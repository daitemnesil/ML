# ML
## Запуск

1. Установите зависимости:
pip install -r requirements.txt

2. Скачайте датасет BODMAS по ссылке: https://drive.google.com/drive/folders/1Uf-LebLWyi9eCv97iBal7kL1NgiGEsv_
3. Положите файлы `bodmas.npz` и `bodmas_metadata.csv` в ту же папку, что и ноутбук.
4. Запустите `malware_detection.ipynb` в Jupyter/Colab.
